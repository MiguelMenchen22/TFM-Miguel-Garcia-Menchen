# TFM-Miguel-Garcia-Menchen
Evaluación de diferentes herramientas de extracción de características de tráfico de red: CICFlowMeter, NEMEA, TStat y Tshark. Generar distintos conjuntos de datos y analizar cómo las características extraídas por cada herramienta influyen en el rendimiento de modelos de aprendizaje automático para la detección de ataques y anomalías en redes IoT.
